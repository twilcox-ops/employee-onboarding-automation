# Synthetic Corpus — Employee Onboarding

This corpus is fictional and intended only for the Project 5 employee-onboarding automation exercise.

Files:
- `new_hires.csv` — 100 synthetic HR onboarding requests.
- `group_mapping.xlsx` — IT department + job-role to standard-group mapping.
- `company_holidays.csv` — fictional company holiday calendar.

The corpus contains routine requests plus deliberate edge/problem cases tied to the confirmed requirements. Do not assume every row is valid or in scope. Inspect the data against `REQUIREMENTS.md` before implementation.

The CSV input and holiday CSV are training interfaces only. They do not establish how the fictional production HR system or holiday calendar integrates.
